# Typography

An editorial motion study in rhythm, contrast, and typographic energy, built to stress-test layout, pacing, and negative space.

## Scope

- Experimental typographic choreography (no product UI)
- Sound-adjacent pacing using only motion and type weight
- Exportable style frames for marketing and portfolio use

## Approach

This was a **pure craft** pass. We treated type as material, using mass, velocity, and silence while saving the flame accent for the moments that earned heat.

## Outcomes

- A reusable set of type-driven transition patterns for future brand work
- A benchmark reel for high-contrast, minimal-color storytelling
- Proof for partners that expressive motion does not require noisy palettes
